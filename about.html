Townsville U3A coding collective

Angry Grannies

are a small Townsville U3A coding collective that creates friendly apps that are fun, accessible and a little bit different. U3A, the University of the Third Age, is a community learning organisation, mostly for seniors, where members share knowledge, learn new skills and take part in interest-based classes.

The Angry Grannies colledctive grew out of the U3A Townsville computer programming class, where participants start from scratch, using Python. The students learn how to program by breaking down problems into small, logical and easy steps and then using those to build the computer code. In many ways, it's like like learning a language.
